# 📰 Morning Download

Daily news briefings covering world events, markets, and AI/agentic systems.

🌐 **Read online:** [morning-download.com](https://morning-download.com/)

Generated by the **Daily News Brief** scheduled task.

## Structure

```
briefs/
  2026-04/
    2026-04-01.md
    2026-04-02.md
    ...
  2026-05/
    2026-05-01.md
    ...
```

Briefings are organized by month under `briefs/YYYY-MM/`. Each file is a standalone daily briefing with two sections:
1. **World & Market Briefing** — geopolitics, macro, markets, M&A
2. **AI & Agentic Systems Briefing** — frontier models, infrastructure, enterprise AI

Some days include additional editions (e.g., `2026-04-06-evening.md`).

## Pull request review automation

Codex reviews pull requests through the repository's native Codex integration, so reviews consume the linked ChatGPT plan's Code Review allowance rather than OpenAI API credits. The `Codex plan review and auto-merge` workflow waits for that native review on the exact pull request head. Every correction push starts a polling gate through GitHub's `synchronize` event, including during this workflow's one-time rollout. After the workflow is present on the default branch, a trusted `@codex review` request and the resulting native Codex event can also restart a gate whose polling window has ended. Review requests and clean results are tied to the exact commit SHA. The workflow never calls the OpenAI API and authenticates only with GitHub's scoped `GITHUB_TOKEN`. A clean, unchanged head is squash-merged automatically only after every status check required by `main` branch protection exists and passes; the workflow fails closed when Codex reports a P0/P1 concern or branch protection has no required checks.
