# 📰 Morning Download

Daily news briefings covering world events, markets, and AI/agentic systems.

Generated by the **Daily News Brief** scheduled task.

## Structure

```
briefs/
  2026-04-01.md
  2026-04-02.md
  ...
```

Each file is a standalone daily briefing with two sections:
1. **World & Market Briefing** — geopolitics, macro, markets, M&A
2. **AI & Agentic Systems Briefing** — frontier models, infrastructure, enterprise AI

Some days include additional editions (e.g., `2026-04-06-evening.md`).
