## Section 2: AI & Agentic Systems Briefing

🏖️ **Akamai put two products into beta on October 27: Akamai Inference, a managed model-serving service, and Akamai Agent Sandbox, an open-source Spin component that uses WebAssembly isolation to cap an agent's compute, memory and outbound connections** — The sandbox's default network policy blocks outbound access from agent-generated code, and the inference launch catalog covers 12 open-weight models behind OpenAI-compatible APIs. **For platform builders:** a CDN-scale vendor is shipping default-deny execution for agent code, which moves "where does agent code run, and what can it reach" from a design option to a baseline expectation. It also follows the sandbox-vendor funding covered here on October 21.

Sources: [Akamai](https://www.akamai.com/newsroom/press-release/akamai-launches-ai-inference-service-and-agent-execution-environment) · [Techzine](https://www.techzine.eu/news/infrastructure/145346/akamai-launches-ai-inference-service-and-agent-sandbox/)

🔌 **AMD reports earnings Tuesday, November 3, one of eight reports the week-ahead previews flag** — With the Nasdaq just having its worst day since June 5, the AI-chip demand commentary on that call is the next hard data point on whether compute spending is slowing. **For enterprise AI delivery:** watch data-center guidance, since it feeds capacity and pricing for the GPU cloud you are buying.

## Closing

**Sleeper Story:** Default-deny networking in agent sandboxes. Why it matters: Akamai's beta blocks outbound access from agent-generated code by default, so isolation vendors are now competing on what an agent *cannot* do. If you build or buy agent platforms, expect competitors to announce matching sandbox controls within weeks, and expect security reviewers to ask for egress policy in your next procurement cycle.

**One-Liner:** Tech ended October on its back foot and starts November with Apple, AMD, the midterms and a jobs report all queued up.
