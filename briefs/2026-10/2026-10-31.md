## Section 2: AI & Agentic Systems Briefing

🔓 **Anthropic's Frontier Red Team used an unreleased internal model to build working exploits for five attack chains, including one-click remote code execution in Chrome and a zero-click Linux kernel exploit** — The October 27 post says the Linux proof of concept took about 48 minutes to leak a kernel pointer and about five more to run a root command, and that vendors patched under a 90-day disclosure window plus a 45-day grace period. Anthropic's argument is that defenders need these models first, and it points to an expanded Cyber Verification Program and a public Claude Code security plugin. **For agentic platform builders:** scan at pull-request time, and expect security reviewers to ask what an autonomous agent with exploit-grade capability can reach in your environment.

Sources: [Anthropic](https://www.anthropic.com/research/discovering-vulnerabilities-with-claude)

🧠 **Mistral's Large 4, a multimodal model of roughly 1.05 trillion parameters with about 49 billion active per query, was slated to get downloadable open weights by the end of October under a custom license rather than Apache 2.0** — Mistral's own timeline put the weights at the end of the month, so the deadline is now. **For anyone building on open weights:** read the license text before committing; a custom license on a model this size sets the commercial-use boundaries for any agent product built on it.

Sources: [BetaNews](https://betanews.com/article/mistral-large-4-preview-open-weights/) · [Forklog](https://forklog.com/en/news/mistral-launches-public-preview-of-ai-model-with-1-trillion-parameters)
