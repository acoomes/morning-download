## Section 2: AI & Agentic Systems Briefing

- 🤖 **Google Cloud Next 2026: Gemini Enterprise Agent Platform, A2A protocol at 150 orgs in production, and a $750M partner fund.** The A2A protocol now lets Salesforce, ServiceNow, SAP, and Atlassian agents interoperate with Google agents — no custom integration code. This is the enterprise multi-agent interop story everyone has been waiting for. If A2A gets broad adoption, it makes Google the connective tissue of the enterprise agent stack. **Directly relevant for agentic platform builders.**

- 🧠 **OpenAI GPT-5.4 Thinking fully deployed — 75% on OSWorld-Verified desktop tasks, surpassing human-level performance.** The "Thinking" variant uses test-time compute to reason before acting, and is now navigating files, browsers, and terminals with minimal human intervention. This is the benchmark that matters for autonomous agent use cases, not chat evals. The bar for "agentic" just moved.

- 🔧 **Anthropic ships Claude Opus 4.7, redesigned Claude Code desktop app, and "Routines" — Enterprise plans now self-serve.** Opus 4.7 is the most capable GA model; Routines (research preview) enables scripted, repeatable agent workflows within Claude Code. Enterprise plans no longer require a sales conversation. All three moves point the same direction: Anthropic commoditizing enterprise onboarding while betting on developer depth.

- 💬 **Salesforce upgrades Slackbot with 30+ agentic capabilities via MCP, running on Claude — Slack is now an agent runtime.** Benioff's demo included meeting transcription, desktop monitoring, third-party tool execution via MCP, and lightweight CRM functions — all in Slack. This is what "ambient AI" looks like in practice. For enterprise builders: Slack is now a deployment surface, not just a notification channel.

- 📊 **Databricks rebrands to Unity AI Gateway — extends catalog governance (permissions, auditing, policies) to agentic AI and MCP servers.** Until now, enterprise AI governance stopped at the model call. Unity AI Gateway applies the same controls to how agents access LLMs and interact with MCP servers. This is the compliance unlock that will determine which agentic deployments actually survive legal review. **Sleeper story for enterprise AI delivery teams.**

- 🔷 **NVIDIA Nemotron 3 open model family debuts — 4x throughput improvement, purpose-built for agentic workloads.** Nemotron 3 Nano delivers 4x higher throughput than its predecessor. For teams running private/on-prem agent infrastructure, this is the headline: capable open models optimized for agent patterns, not just chat.

- 🛠️ **MCP Dev Summit drew 1,200 in NYC; 2026 roadmap targets stateless horizontal scaling and enterprise SSO/auth.** MCP's growing pains are well-documented — stateful servers don't scale behind load balancers, enterprise auth is bolted on. The 2026 roadmap tackles both directly. Clare Liguori and Den Delimarsky joined as maintainers. MCP is graduating from clever protocol to production infrastructure. The question now is how fast enterprise tooling catches the spec.
